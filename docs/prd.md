# Product Requirements Document (PRD)

## 1. Purpose

The **agentcon-pizza-workshop** is an educational toolkit and hands-on workshop designed to teach participants how to build, instruct, and extend AI agents in the context of a pizza business scenario. It provides code samples, documentation, and data to guide users through the process of creating intelligent agents that can interact with business data, tools, and external APIs.

## 2. Target Audience

- AI/ML enthusiasts and developers
- Students and educators in AI/ML courses
- Workshop participants at AI community events
- Developers interested in agent-based architectures

## 3. Features & Requirements

### 3.1. Agent Development
- Python scripts and templates for building AI agents
- Support for stepwise agent enhancement: adding instructions, knowledge, tools, and MCP integration
- Example agents demonstrating increasing complexity and capability

### 3.2. Data Integration
- Sample business data for multiple "Contoso Pizza" locations in markdown format
- Scripts to add and process this data for agent use

### 3.3. Tooling & Extensibility
- Framework for adding custom tools to agents
- Example tools and integration patterns

### 3.4. Documentation & Learning Path
- Step-by-step guides for:
  - Setting up the development environment
  - Creating and instructing agents
  - Adding knowledge and tools
  - Integrating with MCP
- Clear instructions for each workshop step, with code samples

### 3.5. Dashboard & Visualization (Optional/Advanced)
- Reference to a pizza dashboard (for visualizing agent outputs or business data)
- Public assets for integration with external dashboards or APIs

### 3.6. Environment & Dependencies
- Python environment with dependencies specified in `requirements.txt`
- Node.js environment for documentation/dashboard (if applicable)
- Scripts for environment setup and integration with Azure/OpenAI

## 4. Non-Functional Requirements

- Beginner-friendly and well-commented code and documentation
- Modular structure for easy extension and customization
- Cross-platform compatibility (Linux, Windows, Mac)
- Open-source licensing and clear contribution guidelines

## 5. Success Criteria

- Users can follow the documentation to build and run an AI agent for the pizza business scenario
- Agents can process and respond to queries about the business data
- Users can extend agents with new instructions, knowledge, and tools
- The workshop can be run in a classroom or event setting with minimal setup
