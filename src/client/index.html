First-time setup
Chat requires an Azure project connection string.
1) Create .env from .env.example
2) Set PROJECT_CONNECTION_STRING in .env
3) In Codespaces, run az login --use-device-code
4) Restart the server
Tip: .env is gitignored so secrets won't be committed.
